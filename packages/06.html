Package 06 · L3 개발자 × D2 활용

에이전틱 코딩 Level 1-4

Codex · Claude Code · OpenCode 중심 — 차세대 개발 파이프라인 4주 과정

PACKAGE 06 L3 개발자 × D2 활용

💰 단가

₩4,800,000 / Level (4 Level 풀코스 ₩19,200,000)

🎯 타겟

  • 대상: 사내 개발자, IT 부서 엔지니어, 테크 리드 (Python/Node 기초 이상)
  • 기간: Level당 1일 (8시간) · 4 Level 풀 코스 총 32시간
  • AX 단계: 에이전틱 코딩 Level 1-4 (입문→실전→발전→심화)

📝 과정 소개

단순 AI 코드 완성을 넘어, 자율적으로 코드를 설계·수정·테스트하는 '에이전틱 코딩(Agentic Coding)' 실전 과정입니다. 4개 Level이 순차적으로 구성되어, 입문자도 Level 1부터 시작해 4주 과정으로 현업 즉시 투입 가능한 역량을 갖춥니다. 각 Level은 1일 8H 단독 수강도 가능하고, 4주 연속 수강도 가능합니다.

🎯 교육 목표

Codex·Claude Code·OpenCode 각각의 강점이 극대화되는 개발 단계를 식별하고, 실무 프로젝트에 즉시 적용 가능한 도구별 최적 워크플로우를 구축합니다. 프로젝트 스캐폴딩부터 코드 생성·리뷰·디버깅·리팩토링·테스트 자동화·멀티에이전트 오케스트레이션까지 전 과정을 커버하는 실전 감각을 기릅니다.

📋 모듈별 상세 커리큘럼

Level 1 (입문) · 에이전틱 코딩 패러다임 전환
1일 (8H)
도구별 아키텍처 이해와 기본 워크플로우
  • 에이전틱 코딩 패러다임 — 코드 완성(Autocomplete)에서 자율 구현(Agentic Coding)으로
  • Codex · Claude Code · OpenCode 아키텍처 비교 — 클라우드 샌드박스 vs 로컬 터미널 vs 오픈소스
  • [실습] 각 도구 설치 및 기본 조작, 첫 에이전틱 코드 생성 경험
  • [실습] 자연어 요구사항 → 스캐폴딩 자동 생성 체험
Level 2 (실전) · Codex 중심 설계·구현 워크플로우
1일 (8H)
프로젝트 스캐폴딩 · 멀티 파일 생성 · PR 리뷰
  • [실습] 프로젝트 스캐폴딩: 자연어 요구사항 하나로 폴더 구조·설정 파일·보일러플레이트 한 번에 생성
  • [실습] 멀티 파일 코드 생성: 기능 명세 입력 시 연관 여러 파일(API 라우트·컴포넌트·타입 정의) 동시 작성
  • [실습] PR 기반 코드 리뷰: Codex가 생성한 코드를 Pull Request 형태 검토, 자연어로 추가 수정 지시
  • 개발 단계별 최적 배치 전략 — 설계·스캐폴딩(Codex) → 구현·코드 생성(Codex)
Level 3 (발전) · Claude Code 중심 디버깅·테스트 자동화
1일 (8H)
터미널 자율 실행 기반 디버깅·리팩토링·테스트
  • [실습] 터미널 기반 디버깅: 빌드 에러·런타임 오류 발생 시 Claude Code가 로그 직접 읽고 원인 분석·파일 수정
  • [실습] 코드 리팩토링: 기존 코드베이스 분석 → 중복 제거·네이밍 개선·구조 정리 단계적 고도화
  • [실습] 테스트 자동화: 기존 함수 분석 → 단위 테스트 자동 생성 → 실패 케이스 즉시 수정
  • Claude Code + Skills / .cursorrules — 사내 코딩 컨벤션 자동 준수 시스템 구축
Level 4 (심화) · 멀티 도구 오케스트레이션
1일 (8H)
Codex + Claude Code + OpenCode 통합 파이프라인
  • 다중 에이전틱 도구 통합 워크플로우 설계 — 각 도구의 강점을 개발 단계별로 배치
  • [실습] 통합 프로젝트: Codex로 스캐폴딩 → Claude Code로 디버깅 → OpenCode로 로컬 최적화
  • 사내 개발 파이프라인(CI/CD)에 에이전틱 도구 노드 삽입 전략
  • [워크숍] 우리 팀의 에이전틱 코딩 도입 로드맵 수립 — 30일/90일/180일 계획
