Package 08 · L3 개발자 × D4 혁신

하네스 엔지니어링 PoC

에이전트를 위한 인프라 구축 — MCP 활용과 멀티에이전트 CI/CD 파이프라인 통합

PACKAGE 08 L3 개발자 × D4 혁신

💰 단가

₩16,000,000 (4일 32H) + 프로젝트 멘토링 별도

🎯 타겟

  • 대상: CI/CD 자동화 및 개발 파이프라인 설계에 익숙한 시니어/리드 개발자
  • 기간: 4일 (32시간) — 4주 분할(주 1회) 권장, 레벨 간 과제 필수
  • AX 단계: 5단계 (현업 적용 · PoC 고도화)

📝 과정 소개

에이전틱 코딩이 스스로 달리는 '자동차'라면, 하네스 엔지니어링은 다수의 에이전트가 충돌·환각 없이 달리도록 '차선·신호등·목적지 통신망'을 구축하는 고도화 인프라 과정입니다. Model Context Protocol(MCP)을 차용해 에이전트가 사내 시스템·Git·DB와 양방향 연결되어 맥락을 확보하는 환경(Harness)을 구축합니다. 조직 규약을 구조적 제약(Constraints)으로 주입하고, 기존 CI/CD 파이프라인의 각 단계에 전문화된 에이전트 로직을 노드(Node) 형태로 통합합니다.

🎯 교육 목표

멀티에이전트가 사내 도구·문서에 안전하게 연결되도록 MCP 기반 컨텍스트 제공 하네스 환경을 설계합니다. Linter 및 .cursorrules를 활용해 에이전트 환각 활동을 통제하고, 자율형 에이전트 루프를 실제 기업의 개발 라이프사이클(CI/CD 파이프라인)의 적재적소에 내재화합니다.

Level 3 (발전) · 멀티에이전트 자율성 제어 (Architectural Constraints)
1日 (8H)
안전망 및 룰셋팅
  • 자율성과 제어의 타협점 — 조직 규칙·설계 한계를 벗어나지 않도록 멀티에이전트 통제 구조적 제약(Constraints) 주입

  • 계층적 룰 시스템 운영 — 프로젝트 전체 스킬·디렉토리별 제한 지침(.cursorrules) 등 다변화된 룰 상호 작용 구조화
  • [실습] 코딩 컨벤션 위반 시 리뷰 에이전트가 컴파일러 단계에서 감지하고 강제 롤백·에러 수정 요구하는 폐쇄형 제약 사이클
