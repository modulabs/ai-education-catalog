교시주요 주제세부 내용

3교시자동화 — 비대화형·CI/CDcopilot -p "…" -s --no-ask-user · GitHub Actions 삽입 · /every 예약 실행 — 실습: 테스트 커버리지 리포트 자동화
4교시[워크샵] 확장·보안MCP 서버 연결 · Skills·Plugin · preToolUse 훅 정책 · 최소권한 원칙 — 자기 프로젝트 워크플로우 구축·발표

Microsoft Foundry 첫 AI 에이전트 만들기

4H비개발자~주니어입문

MS 공식 학습 랩 "Develop your first AI agent"(약 60분)을 4H로 확장 — 포털에서 프로젝트·모델 배포, 프롬프트 에이전트 저장, SDK 코드화, 함수 툴 확장까지 첫 에이전트와 클라이언트 앱을 완성합니다. 예산 없는 수강생은 Foundry Local(무료·구독 불필요)로 대체 실습 가능.

교시주요 주제세부 내용
1교시Foundry 첫걸음 — 프로젝트·모델 배포신 포털 구조(Build/Discover) · 프로젝트 생성 · gpt-5-mini 배포 · 플레이그라운드 · 모델 카탈로그(instant access)
2교시첫 에이전트 (포털+프롬프트)시스템 프롬프트 설계 · 웹검색 툴 부착 · Save as agent(YAML 정의) · 프롬프트 에이전트 개념
3교시SDK로 코드화AIProjectClient · create_version(PromptAgentDefinition) · 멀티턴 대화 · Responses API
4교시툴 확장 + 클라이언트 앱커스텀 함수 툴 · MCP 연결 소개(심화 예고) · Flask 클라이언트로 에이전트 호출·시연
실습 전제: Azure 구독(무료 계정 $200 크레딧) · Python 3.10+/VS Code · 토큰 비용 미미 · 대안: Foundry Local(무료, GPU 권장)

4H개발자중급

MS 공식 RAG 튜토리얼 3부(환경구축·빌드·평가)를 4H로 압축 — 포털형 RAG(문서 업로드→인덱싱→grounded 채팅)에서 시작해 SDK형 RAG(벡터 검색·Prompty 템플릿)까지. 수료 산출물: 자사 문서 기반 RAG 챗앱(인용 포함).

교시주요 주제세부 내용
1교시RAG 개념 + 데이터 연결Retrieve→Augment→Generate 3단계 · 임베딩/인덱스 개념 · chat+embedding 모델 2개 배포 · AI Search 연결
2교시포털형 RAG문서 업로드 · 인덱스 자동 생성 · grounded 채팅 · citations 확인
3교시SDK형 RAG 코드SearchClient + VectorizedQuery · intent mapping(검색어 변환) · Prompty 템플릿 · grounded chat 완성
4교시하이브리드 검색 + 심화 예고BM25+벡터 하이브리드 · 리랭킹·청킹 전략 · agentic retrieval(MCP) 데모 — 심화 12H(클-개-3-002) 브리징
실습 전제: AZ-101 수료 권장 · Azure AI Search Free 티어(50MB·3인덱스 무료) 또는 Basic · 수업 후 리소스 삭제 권장(provisioned 과금)

Foundry 에이전트 평가·안전 운영

4H개발자·플랫폼중상급

AZ-101의 에이전트와 AZ-102의 RAG 앱을 평가 대상으로 그대로 재사용하는 누적형 과정. 내장 평가자(품질·에이전트·리스크)로 정량 평가하고, Prompt Shields·Guardrails로 안전장치를 적용 — AI-103 시험의 최대 비중 도메인을 직격 커버합니다.

교시주요 주제세부 내용
1교시품질 평가 개념 + 내장 평가자coherence·fluency·relevance·groundedness / intent_resolution·task_adherence · 플레이그라운드 내장 평가 체험
2교시평가 실행 — 데이터셋→런→리포트JSONL 테스트셋 작성 · eval.yaml/포털 위저드 · 루브릭 평가자 · 임계값 설정·해석
3교시안전 평가 + Red Teaming4대 리스크 카테고리(0-7 심각도) · 간접 프롬프트 인젝션(XPIA) · AI red teaming 에이전트 소개
4교시[워크샵] Guardrails + 운영화콘텐츠 필터(심각도 슬라이더) · Prompt Shields(프롬프트+문서 공격) · tracing·Azure Monitor 알림 구성
실습 전제: AZ-101·AZ-102 산출물 보유(평가 대상) · 평가·안전 평가자는 소비량 기반 과금(리전 제한 확인)
