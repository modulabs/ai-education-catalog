Microsoft Foundry 첫 AI 에이전트 만들기

4H비개발자~주니어입문

첫 에이전트와 클라이언트 앱 완성 — 포털 배포부터 SDK·함수 툴까지. 예산 없으면 Foundry Local(무료)로 실습 대체.

교시주요 주제세부 내용
1교시AI 서비스 기반 한 번에 갖추기
Foundry 첫걸음 — 프로젝트·모델 배포		신 포털 구조(Build/Discover) · 프로젝트 생성 · gpt-5-mini 배포 · 플레이그라운드 · 모델 카탈로그(instant access)
2교시질문에 답하는 나만의 AI 만들기
첫 에이전트 (포털+프롬프트)		시스템 프롬프트 설계 · 웹검색 툴 부착 · Save as agent(YAML 정의) · 프롬프트 에이전트 개념
3교시코드로 다루는 에이전트로 확장
SDK로 코드화		AIProjectClient · create_version(PromptAgentDefinition) · 멀티턴 대화 · Responses API
4교시외부 기능 연결한 실서비스형 에이전트
툴 확장 + 클라이언트 앱		커스텀 함수 툴 · MCP 연결 소개(심화 예고) · Flask 클라이언트로 에이전트 호출·시연
실습 전제: Azure 구독(무료 계정 $200 크레딧) · Python 3.10+/VS Code · 토큰 비용 미미 · 대안: Foundry Local(무료, GPU 권장)

Foundry + Azure AI Search RAG 앱 만들기

4H개발자중급

자사 문서로 "근거 있는 채팅" 만들기 — 문서 업로드→인덱싱→인용 확인→하이브리드 검색. 수료 산출물: 자사 문서 RAG 챗앱.

교시주요 주제세부 내용
1교시AI가 사내 문서를 찾아 읽게 하는 원리
RAG 개념 + 데이터 연결		Retrieve→Augment→Generate 3단계 · 임베딩/인덱스 개념 · chat+embedding 모델 2개 배포 · AI Search 연결
2교시문서 올리면 바로 답하는 챗봇
포털형 RAG		문서 업로드 · 인덱스 자동 생성 · grounded 채팅 · citations 확인
3교시우리 서비스에 붙이는 검색·응답 코드
SDK형 RAG 코드		SearchClient + VectorizedQuery · intent mapping(검색어 변환) · Prompty 템플릿 · grounded chat 완성
4교시검색 정확도 끌어올리기
하이브리드 검색 + 심화 예고		BM25+벡터 하이브리드 · 리랭킹·청킹 전략 · agentic retrieval(MCP) 데모 — 심화 12H(클-개-3-002) 브리징
실습 전제: AZ-101 수료 권장 · Azure AI Search Free 티어(50MB·3인덱스 무료) 또는 Basic · 수업 후 리소스 삭제 권장(provisioned 과금)
AZ-103 · STEP 3 운영 · 클-전-3-001

Foundry 에이전트 평가·안전 운영

4H개발자·플랫폼중상급

만든 것을 운영 수준으로 — 품질·위험 평가, 프롬프트 방어·콘텐츠 필터 적용. AZ-101·102 산출물을 평가 대상으로 재사용(누적형). AI-103 시험 최대 비중 도메인 대응.

교시주요 주제세부 내용
1교시"좋은 답변"을 숫자로 측정하기
품질 평가 개념 + 내장 평가자		coherence·fluency·relevance·groundedness / intent_resolution·task_adherence · 플레이그라운드 내장 평가 체험
2교시시험 문제 만들어 점수 내기
평가 실행 — 데이터셋→런→리포트		JSONL 테스트셋 작성 · eval.yaml/포털 위저드 · 루브릭 평가자 · 임계값 설정·해석
3교시공격 시도해 보고 막기
안전 평가 + Red Teaming		4대 리스크 카테고리(0-7 심각도) · 간접 프롬프트 인젝션(XPIA) · AI red teaming 에이전트 소개
4교시[워크샵] 안전장치 설정·상시 감시
Guardrails + 운영화		콘텐츠 필터(심각도 슬라이더) · Prompt Shields(프롬프트+문서 공격) · tracing·Azure Monitor 알림 구성
실습 전제: AZ-101·AZ-102 산출물 보유(평가 대상) · 평가·안전 평가자는 소비량 기반 과금(리전 제한 확인)
